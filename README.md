# Critter Climb Arena

내가 만들 게임은 서로 각각 다른 곳에 들어오지 않고 모두 같은 서버에 들어가서 경쟁하는 2D 점프맵을 만들려고 한다. 게임의 목표는 점프맵 꼭대기에 제일 빠른 시간에 도달하면 승리하는 방식의 게임이다. 조작 방식은 다음과 같다. 키보드로 조작을 하는거고 조작 방법은 스페이스에 점프키고 s키는 뒤로 가는 거고, d키는 앞으로 가는키다.또 a키는 다른 사람을 밀치는 키로 딱 그 서버에서는 10번만 쓸수 있게 한다. 게임 규칙의 경우, 처음 들어가면 그냥 서버를 생성 할 수 있지만 친구 서버에 들어가고 싶으면 그 서버의 이름이 "1234"면 거기에 들어가는 곳을 따로 만들어서 그 "1234"를 치면 그 친구 서버에 들어갈 수있다. 승리의 조건은 따로 존재하지 않고 목표와 같다고 볼 수 있다. 실패 조건도 따로 없고, 목표를 클리어하면 게임이 종료됩니다. 디자인의 경우 캐릭터는 동물로 고양이,강아지,햄스터,아주 너무나 귀여운 외계인 캐릭터가 있고 디자인은 귀여운 스타일점프맵과 또 다른 점프맵은 5학년 아이들이 무섭지는 않지만 살짝 무섭게 점프맵으로 두가지 점프맵을 고를 수 있다.
